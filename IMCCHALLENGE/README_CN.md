## 概述

给定一个封闭、水密的二维流形三角网格（最多 110 万顶点），任务是在保持结果与原始网格视觉不可区分的前提下，尽可能多地删除顶点。视觉保真度由六相机渲染管线判定：平面着色法线图和透视校正深度图，分辨率 1024×1024，通过 11×11 滑动窗口 SSIM 评分，合格线为 0.90。每个网格得分为 $S = 100(1 - V'/V)$，取六个隐藏网格的平均值。每个网格限 21 秒 CPU 时间，C++ 源代码不超过 131072 字节。

我们的求解器将二次误差度量（QEM）边坍缩扩展为**双阶段流水线**：

1. **无渲染批量阶段。** 边的优先级由一个加权二次型代价函数决定，该代价融合了面片投影覆盖率、法线轴向对齐度、轮廓暴露度以及邻域法线一致性 —— 全部由一次性六视图光栅化预计算得到。此阶段完成了 96.4%–99.8% 的顶点删除，全程不调用渲染器。

2. **评估器门控精炼阶段。** 求解器内部嵌入了六相机评估器的忠实复刻。每个候选坍缩仅重新渲染受影响的像素区块，增量更新六视图得分，只有当*预测的全局* SSIM 仍高于校准的接受阈值时才被接受。核心之外配有四项度量对齐机制、能够触达优先队列永远无法弹出的顶点的几何操作，以及六个顶点数量区间。

## 架构

```
输入网格
  │
  ├── 一次性六视图光栅化（覆盖率、轮廓、曲率）
  │
  ├── [批量阶段] 代理引导的 QEM 边坍缩
  │     - 加权二次型：面积 × 轴向对齐 × 覆盖率 × 轮廓
  │     - 感知边排序（5 项感知代价项）
  │     - 顶点重要性加权（可见性 × 粗糙度）
  │     - 运行至各区间顶点目标或队列为空
  │
  ├── [预坍缩松弛] 平面投影 + 顶点法线精炼
  │
  ├── [额外坍缩] 两次由代理评分的坍缩遍（不经过评估器复刻）
  │
  ├── [精炼阶段] 评估器复刻门控的边坍缩
  │     - 增量区块渲染（仅受影响的一环邻域）
  │     - 基于积分图（SAT）的 SSIM，常数预乘消去除法
  │     - 预测全局 SSIM 门控（从不使用局部比较）
  │     - 自适应截止时间调度
  │
  ├── [几何操作]
  │     - 扇形三角剖分顶点移除（平面星形区域）
  │     - 共面对插入（购买 SSIM 余量，仅 R2）
  │     - 隐藏区域坍缩（深度缓冲区认证）
  │     - 多候选位置优化（最多 16 个位置）
  │
  ├── [合并扫描] 穷举的朝向门控逐对顶点合并
  │
  └── 输出简化网格
```

## 核心组件

### 带感知代价项的加权 QEM

经典 QEM 最小化到原始面片支撑平面的平方距离。我们对每个面片的二次型施加四个权重因子：三角形面积 $A_f$、轴向对齐度 $\alpha_f$（被六个轴向相机正视的面片）、投影像素覆盖率 $\gamma_f$ 和可见性门控项 $\nu_f$。总边坍缩代价将几何二次型误差与五项感知项通过乘性因子和下界结构组合在一起。

### 度量对齐

四项修正使内部代理与评估器保持一致：
- **相机校准：** 可见性预扫描使用与评估器一致的相机参数
- **逐视图归一化：** 面片贡献在各视图内归一化，尊重评估器 1/6 等权平均的评分结构
- **顶点重要性：** 覆盖率 × 粗糙度重新加权，带地板和上界保护
- **SSIM 亮度不对称性：** 逐通道亮度损失在位置选择、精炼和合并路径中替代对称的 1-dot

### 校准的接受阈值

局部 SSIM 评估器在隐藏网格上系统性地高估评判分数。接受阈值（$\tau = 0.90425$–$0.9090$）通过对评估反馈进行二分搜索来校准 —— 逐步降低 $\tau$ 直到出现错误判定，然后将运行点设在刚好通过的位置。精炼阶段检查*预测的全局* SSIM，从不使用局部估计。

### 高效求值

- **代数除法消除：** 将 SSIM 常数预乘 $121^2$，消除所有逐窗口除法
- **光栅跨度收紧：** 最小 1 像素包围盒填充
- **区块细分：** 按区间设置区块粒度（从 $32\times32$ 到 $5\times5$ 像素），权衡哈希开销与误报面-区块测试
- **自适应截止时间：** 由实测渲染代价计算停止时间，在坍缩循环内高频轮询 CPU 时钟

### 几何操作

触达普通边坍缩无法消除的顶点的操作：
- **扇形三角剖分：** 通过重新三角剖分一环边界来移除平面扇形顶点
- **共面对插入：** 添加重合面对以购买 SSIM 余量，随后用于进一步删除
- **隐藏区域坍缩：** 经深度缓冲区认证，删除在所有六个视图中均不可见的顶点
- **合并扫描：** 穷举的逐对顶点合并，以逐面法线偏差为门控

### 区间自适应架构

六个顶点数量区间（R1: ≤1万 → R6: >70万）各自拥有独立的参数和阶段激活配置。绑定约束随规模变化：小网格受限于 SSIM 质量余量，中网格受限于平面冗余，大网格受限于 CPU 吞吐量。

## 构建与运行

### 编译
```bash
g++ -O2 -std=c++17 final.cpp -o simplify
```

### 运行
```bash
./simplify < input_mesh.in > output_mesh.out
```

输入为修改后的 OBJ 格式：第一行 `V F`，随后为 `v x y z` 行，然后为 `f v1 v2 v3` 行（索引从 1 开始）。输出遵循相同格式。

### 源码尺寸限制
评判机使用 `g++ -O2` 在 x86 上编译，强制 131072 字节源码限制。开发在可读、带注释的版本（3400+ 行）上进行；通过压缩流水线（注释去除 + 标识符重命名 + 迭代碰撞排除）生成提交用的压缩源码。
